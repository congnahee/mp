서버 DB (이 프로젝트를 올린 Vercel, 추천)

연결 상태연결 안됨
별도 계정 없이, Vercel Storage에서 Upstash 하나만 연결하면 바로 써요. 같은 동기화 키를 입력한 모든 기기가 몇 초 간격으로 같은 데이터를 봐요.

⚠ 동기화 키를 아는 사람은 누구나 접근할 수 있어요. 외부에 공유하지 마세요.

Firebase 실시간 동기화 (선택)

연결 상태연결 안됨
Firebase Realtime Database 주소와 동기화 키를 입력하면, 같은 값을 입력한 모든 기기가 실시간으로 같은 데이터를 봐요. 설정 방법은 채팅에서 안내해드려요.
Firebase에 연결하면 현재 상황을 직접 저장할 수 있어요.
⚠ 이 방식은 URL과 동기화 키를 아는 사람은 누구나 접근할 수 있어요. 외부에 공유하지 마세요.
